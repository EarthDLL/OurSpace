# 部署与使用

全程大约 20 分钟。你只需要准备：一台常年开机的电脑或服务器、两部安卓手机（Android 8.0 以上）。

---

## 一、后端（10 分钟）

### 1. 装 Node.js
需要 **Node.js ≥ 22.5**（用到内置的 `node:sqlite`，后端因此**不需要任何 npm 依赖**）。
验证：`node -v` 输出 `v22.x` 或更高。

### 2. 配置

```powershell
cd backend
copy config.example.json config.json
```

编辑 `config.json`，逐项说明：

| 字段 | 说明 |
|---|---|
| `port` | 监听端口，默认 `8080` |
| `host` | 默认 `0.0.0.0`，表示局域网/公网都能连 |
| `tls.enabled` | 是否由本服务直接跑 HTTPS。放在 Nginx/Caddy 后面时保持 `false` |
| `tls.cert` / `tls.key` | 证书与私钥文件路径（`tls.enabled=true` 时必填） |
| `payloadSecret` | **配对密钥**：一串长随机字符。手机 App 里要填一模一样的串。它是内容加密的密钥，泄露=内容可解 |
| `jwtSecret` | 登录令牌签名密钥，**必须与 payloadSecret 不同** |
| `amapKey` | 高德 Web 服务 API Key，用于经纬度转文字地址。留空则地址显示为空 |
| `db` | SQLite 文件路径，默认 `data/ourspace.db` |
| `retentionDays` | 保留天数，默认 `7` |
| `liveIntervalSec` / `statsIntervalSec` | 提示客户端的上报周期，默认 60 / 600 秒 |

生成两串随机密钥（各跑一次）：

```powershell
node -e "console.log(require('crypto').randomBytes(32).toString('base64url'))"
```

### 3. 高德 Key
到 [高德开放平台](https://lbs.amap.com/) 注册 → 应用管理 → 创建应用 → 添加 Key → **服务平台选「Web服务」**（不是 Android 平台）。把 Key 填进 `amapKey`。

### 4. 建号 + 配对（只能在后端做，App 里没有注册功能）

```powershell
node src/cli.js adduser alice 给alice设的密码
node src/cli.js adduser bob   给bob设的密码
node src/cli.js link alice bob        # 把两人配成一对
node src/cli.js list                  # 确认结果
```

### 5. 启动

```powershell
node src/server.js
```

看到监听日志即可。浏览器访问 `http://<服务器IP>:8080/api/v1/health`，返回 `{"ok":true,...}` 说明正常。

### 6. 让它常驻

**Windows**（任务计划程序 → 创建任务 → 触发器「计算机启动时」→ 操作「启动程序」）：

```
程序：  D:\Program Files\DSH\node\node.exe
参数：  src\server.js
起始于：C:\你的路径\OurSpace\backend
```

**Linux systemd**（`/etc/systemd/system/ourspace.service`）：

```ini
[Unit]
Description=OurSpace backend
After=network.target

[Service]
WorkingDirectory=/opt/ourspace/backend
ExecStart=/usr/bin/node src/server.js
Restart=always

[Install]
WantedBy=multi-user.target
```

### 7. 外网访问（可选，但推荐）

两人不在同一局域网时，需要把端口暴露出去。**三种方式，任选**：

| 方式 | 做法 | 安全性 |
|---|---|---|
| 内网穿透 | frp / tailscale / zerotier，手机连同一虚拟内网 | 好，端口不暴露公网 |
| Caddy 反代 | `caddy reverse-proxy --from your.domain --to 127.0.0.1:8080` | 最好，自动 HTTPS |
| 直接暴露 | 路由器端口映射 + `config.tls.enabled=true` + 证书 | 必须配证书 |

> 无论哪种，业务内容本身都已经过 AES-256-GCM 信封加密，明文 HTTP 抓包也看不到位置、WiFi、应用列表。但仍建议叠加 HTTPS，避免流量特征与令牌被嗅探。

## 二、客户端（10 分钟）

### 1. 拿到 APK

直接用已编译好的**正式签名包**：`dist/OurSpace-release.apk`（0.7 MB）。

想自己重新编译：

```powershell
powershell -ExecutionPolicy Bypass -File tools/build-apk.ps1 -Release
# 产物：android/app/build/outputs/apk/release/app-release.apk
```

> 需要 JDK 17~21。如果本机只有 JDK 25，用方式 B。

**方式 B：Android Studio（推荐给不熟命令行的人）**
1. Android Studio → Open → 选中 `android` 目录
2. 等 Gradle Sync 完成（首次会下载 Gradle 8.11.1 和依赖）
3. `Build` → `Build Bundle(s) / APK(s)` → `Build APK(s)`（默认出 debug 包）
   要出正式包：`Build` → `Generate Signed App Bundle / APK`

### 1.1 关于签名（很重要，别跳过）

正式包用独立密钥签名，文件在：

| 文件 | 说明 |
|---|---|
| `android/keystore/ourspace-release.jks` | 签名密钥，**必须单独备份** |
| `android/keystore.properties` | 密钥口令（同样别丢） |

当前密钥指纹：

```
Alias    : ourspace
SHA-1    : 54:58:64:5F:7B:66:60:28:9F:1C:87:81:20:C9:67:B0:22:41:FF:97
SHA-256  : 7F:9B:41:B7:65:F9:C0:F9:98:AC:E9:40:4C:85:C1:A3:7A:A7:54:A8:37:69:B7:36:EF:EE:23:A3:9A:1A:F6:D8
```

**为什么必须备份**：Android 只允许「同一个签名」的包覆盖安装。jks 丢了以后，
你只能卸载重装，本机 7 天历史会没掉（服务端还有，重新登录后会拉回来）。

**debug 包和 release 包签名不同，不能互相覆盖。**
如果你手机上装的是 `OurSpace-debug.apk`，要装 release 包必须先卸载：

```powershell
& "D:\AndroidSDK\platform-tools\adb.exe" uninstall com.ourspace.app
```

卸载会清掉本机的登录状态与本地历史，重装后需要重新登录（服务端数据会在同步后拉回来）。

### 2. 装到手机
把 `app-debug.apk` 传到手机安装（需允许「安装未知来源应用」）。两部手机都装。

### 3. 首次配置
打开 App，填：

- **服务器地址**：`http://192.168.1.5:8080`（局域网）或 `https://your.domain`，**结尾不要带斜杠**
- **配对密钥**：和后端 `config.json` 里的 `payloadSecret` **一字不差**
- **用户名 / 密码**：第 4 步建的账号，A 手机填 alice，B 手机填 bob

点登录。

### 4. 权限引导（每部手机都要做，顺序别乱）

| 顺序 | 权限 | 为什么需要 |
|---|---|---|
| 1 | 使用情况访问权限 | 应用使用时长、应用使用记录的唯一来源，**不开启则统计和瞬间列表是空的** |
| 2 | 定位权限（先「仅在使用时允许」，再回设置页改成「始终允许」） | 位置共享。Android 要求先给前台定位才能申请后台定位 |
| 3 | 通知权限（Android 13+） | 前台服务常驻通知，没有它服务会被限制 |
| 4 | 忽略电池优化 | 阻止系统在息屏后冻结采集服务 |
| 5 | 厂商自启动 | 见下 |

**厂商自启动设置**（不做的话，锁屏一段时间后 App 会被杀，数据就断了）：

- **小米 / Redmi**：设置 → 应用设置 → 应用管理 → OurSpace → 自启动 打开；省电策略改为「无限制」；最近任务里给 App 加锁
- **华为 / 荣耀**：设置 → 应用 → 应用启动管理 → OurSpace → 关掉「自动管理」，三项全部手动打开
- **OPPO / 一加 / realme**：设置 → 电池 → 应用耗电管理 → OurSpace → 允许后台运行 + 允许自启动
- **vivo / iQOO**：设置 → 电池 → 后台高耗电 → 允许；i管家 → 自启动管理 → 允许
- **三星**：设置 → 电池 → 后台使用限制 → 把「OurSpace」加入「永不进入休眠的应用」
- **原生 / Pixel**：设置 → 应用 → OurSpace → 电池 → 不受限制

### 5. 解锁记录开关（可选，默认关闭）

设置页 → 「共享手机解锁记录」→ 弹出二次确认 → 阅读后确认才会开启。

- 该开关**默认关闭**，不开启就完全不采集解锁时间。
- 双方都可以独立开启/关闭。
- 如果本机系统不支持（例如某些定制 ROM 屏蔽了 `ACTION_USER_PRESENT` 广播），App 会**自动把开关关回去**并提示「本机系统不支持解锁记录，已自动关闭」。

### 6. 暂停共享

概览页顶部的「我的共享」开关，关掉后：
- 手机**立即停止一切上传**，不再向服务器发任何数据；
- 本地仍继续记录（方便你自己回看），恢复后按 7 天窗口补传最近的数据；
- 对方会看到「对方已暂停共享」而不是看到过期的旧数据。

## 三、日常

- **看对方状态**：概览页，内容 60 秒内更新。
- **看瞬间记录**：瞬间页，可切「我 / 对方」，可选最近 7 天任意一天。
- **看统计**：统计页，应用排行 + 24 小时分布 + 近 7 天柱状图。

## 四、备份与维护

- **备份**：停掉后端，复制 `backend/data/ourspace.db` 即可；恢复就复制回去。
- **改密码**：`node src/cli.js passwd alice 新密码`
- **解除配对**：`node src/cli.js unlink alice`
- **清空历史**：删掉 `data/ourspace.db`，重启后端（账号需要重建）。
- **数据留存**：服务端每小时清理一次，超过 7 天的记录自动删除；手机本地库同样只留 7 天。

## 五、常见问题

**Q：后端能连上，但 App 里数据一直是空的？**
先看设置页的权限引导——90% 是「使用情况访问权限」没开。另外确认两部手机填的 `配对密钥` 完全一致。

**Q：地址显示为空？**
`amapKey` 没填、填错，或者高德 Key 的服务平台选成了「Android」而不是「Web服务」。也可能是手机没拿到定位（室内 GPS 弱，等 1~2 分钟或到窗边）。

**Q：过了几小时就没数据了？**
服务被系统杀了。检查：忽略电池优化是否已授权、厂商自启动是否已开、通知权限是否给了（前台服务通知被屏蔽会导致服务受限）。

**Q：对方显示「已暂停共享」？**
对方主动关掉了共享开关，这是设计行为。

**Q：抓包能看到我的数据吗？**
看到的是 `{"e":"<base64>"}`。内容用 AES-256-GCM 加密，密钥由双方手机里的 `payloadSecret` 派生，服务器配置文件里也有一份。装了 HTTPS 之后更是双重加密。

**Q：App 会耗很多电吗？**
60 秒一次电量/WiFi 读取，600 秒一次用量统计查询，都是轻量系统 API；位置只请求单次更新，不持续持有 GPS。日常耗电可忽略。
